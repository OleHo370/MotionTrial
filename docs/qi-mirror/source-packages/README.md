# Original Qi Mirror import packages

The integrated source, artwork, fonts, licenses and provenance are versioned in
`app/qi-mirror/`, `features/qi-mirror/`, `public/qi-mirror/` and `docs/qi-mirror/`.
The original import ZIPs are redundant local backups, excluded from Git to keep
the working source tree focused. They are not required to run or build Qi Mirror.
Existing local copies are retained. Earlier repository history also preserves
the original imports.
